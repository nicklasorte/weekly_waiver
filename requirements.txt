# Exact pins, not floors.
#
# This is an application with one execution path, not a library other code
# resolves against, so a loose bound buys nothing and costs reproducibility.
# models/*.joblib are fitted estimators committed to the repo and unpickled by
# `make weekly`; the scheduled job never refits them. Under `scikit-learn>=1.3`
# the day a new minor ships is the day the weekly table starts scoring through
# a library the models were never fit under, and the failure mode is not a
# crash -- it is a table of slightly different numbers with nothing to signal
# that anything moved.
#
# Every direct dependency is pinned rather than only the numeric stack: pyyaml
# parses the roster that decides which drops a report proposes, so its version
# reaches the output too. Transitive dependencies (narwhals, threadpoolctl,
# six, python-dateutil) are deliberately not pinned here -- that is a lockfile,
# and the backstop that actually protects the numbers is the fit-version
# assertion in src/models.py, which compares the versions recorded inside each
# bundle against the running ones and refuses to serve a mismatch.
#
# To move a pin: change it here, `make install`, then `make models` to refit
# the bundles under the new versions. Bumping a pin without refitting is what
# the load-time assertion exists to stop.
